# Coworking-Space-Database-Management-System.
Sistem database PostgreSQL untuk manajemen coworking space. Dilengkapi fitur automasi business logic menggunakan Triggers (cegah double booking, auto-update stok F&amp;B) serta Role-Based Views untuk dasbor analitik divisi Manajer, Keuangan, dan Pemasaran.
